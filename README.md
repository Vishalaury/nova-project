# NOVA — Team Productivity Platform

> Plan. Collaborate. Deliver.

NOVA is a full-stack project management application built for teams to manage projects, tasks, team members, and project progress from a single platform.

## 🚀 Live Demo

**Frontend:** https://nova-project-beta.vercel.app

**Backend:** https://nova-project-ju6w.onrender.com

## ✨ Key Features

- Secure user registration and login with JWT authentication
- Role-based access control (RBAC)
- Create, update and manage projects
- Create and manage project tasks
- Assign tasks and track task status
- Team member management
- Project progress tracking
- Dashboard for projects and tasks
- Protected API routes
- RESTful backend APIs
- Responsive and user-friendly interface

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, Tailwind CSS, Axios, React Router

**Backend:** Node.js, Express.js, MongoDB, Mongoose

**Authentication:** JWT, bcrypt

**Deployment:** Vercel, Render, MongoDB Atlas
